Firebase 연결 전입니다

실시간 문의·후기를 관리하려면 아래 순서로 연결해 주세요.

  1. Firebase 프로젝트 생성 → 웹 앱 추가 → 연결 정보를 firebase-config.js에 붙여넣기
  2. Firestore Database 만들기 → 규칙 탭에 firestore.rules 내용 붙여넣고 게시
  3. Authentication → 이메일/비밀번호 사용 설정 → 관리자 계정 추가
  4. Firestore에 admins 컬렉션 → 문서 ID를 관리자 계정의 UID로 만들기

기존 관리자 페이지(샘플 데이터 관리)로 가기
